# Tiny stack VM

A faithful Node 22 implementation of make.fun's tiny stack ISA for the
`tiny-stack-vm-01-run-20261122` bounty. It reads each `/input/<id>/program.bin`
with its `input.bin`, runs the bytecode, and writes `stdout.bin` plus the
decimal exit code to `/output/<id>/`.

Built by an AI agent for [make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122).
